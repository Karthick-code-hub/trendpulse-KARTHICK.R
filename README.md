TrendPulse – What's Actually Trending Right Now?


TrendPulse is a Python-based data collection, cleaning, analysis, and visualization project that explores trending stories from the Hacker News API. It collects story information, classifies stories into broad categories, prepares a clean dataset, calculates engagement statistics, and generates charts to make trends easier to understand.
Project Workflow
The project is organized into four tasks:
1. Data Collection – Fetches top story IDs and story details from the Hacker News API. It assigns stories to categories using title keywords and saves the collected records as a dated JSON file in data/.
2. Data Processing – Loads the latest collected JSON file, removes duplicate and incomplete records, converts numeric fields, filters stories with a score below 5, and saves the cleaned data as data/trends_clean.csv.
3. Data Analysis – Calculates summary statistics such as average score, average comments, mean, median, standard deviation, maximum and minimum score. It also identifies the category with the most stories and the most-commented story, creates engagement/popularity columns, and saves data/trends_analysed.csv.
4. Data Visualization – Creates charts for the top 10 stories by score, story counts by category, and score versus comments. It also creates a combined dashboard. Generated images are saved in outputs/.
Technologies Used
- Python – Project programming language
- Requests – Fetching data from the Hacker News API
- Pandas – Data loading, cleaning, transformation, and analysis
- NumPy – Numerical statistics
- Matplotlib – Data visualization
- JSON / CSV – Data storage formats

Getting Started
1. Clone the repository
git clone https://github.com/Karthick-code-hub/trendpulse-KARTHICK.R.git
cd trendpulse-KARTHICK.R
2. Create and activate a virtual environment (recommended)
Windows PowerShell:
python -m venv .venv
.\.venv\Scripts\Activate.ps1
macOS / Linux:
python3 -m venv .venv
source .venv/bin/activate
3. Install dependencies
python -m pip install requests pandas numpy matplotlib
Run the Project
Run the scripts from the repository's root directory, in this order:
python task1_data_collection.py
python task2_data_processing.py
python task3_analysis.py
python task4_visualization.py
Each task uses the output created by the previous task. Run Task 1 first so that the data/ folder contains a collected JSON file.

Analysis Highlights
- Story distribution across Technology, World News, Sports, Science, and Entertainment categories.
- Story scores and comment activity.

- Most represented category and most-commented story.
- Engagement ratio and a popularity flag based on the average score.
Data Source
Story data is retrieved from the public Hacker News Firebase API. The collected data can change each time the scripts are run.
Notes
- An internet connection is required for Task 1 because it retrieves live data from the Hacker News API.
- Tasks 2–4 use the files generated by earlier tasks.
- Run commands from the project root so the relative paths to data/ and outputs/ resolve correctly.
- The actual number of collected stories may vary depending on the stories returned by the API and the keyword-based category matching.
